# Spatial portfolio iteration

1 November 2026. This revision supersedes the compact diagram and repeated project artwork from the earlier motion pass.

## Pass 1 — composition

The old hero used a tall framed control panel around a small, dark graph. Replaced it with an open 430px desktop stage: three ivory evidence sheets, a copper processor with separate fins and pins, and an output document. The scene assembles on entry, papers float, source signals move, and selecting Context separates the processor layers. Native controls still own the explanation and provenance.

Added a copper scroll sequence for Build, Connect and Automate. It uses natural document scroll, a sticky stage, interpolated text transforms, progress and chapter numerals. Project artwork now has distinct compositions: a voice/memory fan for Synora, an evidence trail for ContextGuard, the actual TermWise interface, and an identity/ledger illustration for the blockchain project. Artwork responds to pointer movement. The homepage project index now navigates to project anchors.

## Pass 2 — visual review and repairs

Inspected desktop and mobile captures. Fixed a 320px contact-heading overflow found by browser testing. Raised mobile story typography and centered its content; tightened mobile hero spacing; changed the fallback diagram to ivory paper and copper; replaced the awkward split CONTEXT label; allowed DPR up to 2 while retaining the frame cap. Removed superseded layout overrides and minified the combined CSS. The stylesheet budget is now 45KB, including the separate scroll sequence.

## Pass 3 — regression and motion evidence

All six static test groups, 104 core browser assertions, 25 existing motion checks, and 60 additional spatial checks passed. Zero runtime errors or failed asset requests were recorded. The new tests compare actual WebGL frames to establish movement, stable pause and resumed rendering; they also exercise all three scroll phases, project anchor landing, actual screenshot loading, pointer tilt/reset, 18 overflow positions across six widths, and reduced-motion restoration. Evidence is in `spatial-results.json` and `screenshots/spatial/`.

The walkthrough in `motion-preview.webm` is an actual browser recording, kept local rather than shipped as an autoplay asset. The new 3D model remains a conceptual illustration, not a performance benchmark of the featured applications.

## Access and behavior

Mobile, reduced-motion and WebGL failure retain semantic SVG and native controls. Reduced motion displays all scroll-story copy in normal flow. There is no custom cursor, wheel interception, scroll snapping or invented performance data. Offscreen and hidden-page rendering pauses; resource disposal remains in place. The copper/ivory/charcoal palette and project priority are preserved.
